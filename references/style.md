# 视觉规范细则

这套风格的辨识度不来自某一个元素，而是来自「纸张、墨、一个荧光色」的克制 + 极端的字号对比 + 网格化的仪表感。任何一处放松，就掉回普通的 PPT 动效。

## 1 配色

```
纸  #EDE9E1   米白，不是纯白。纯白会让整片像 UI 截图
墨  #0F1211   近黑，带一点绿。纯黑显廉价
强调 #2FD6A3  薄荷绿。深色卡上用这个
强调深 #0B8F68 浅色卡上用这个（#2FD6A3 在白底上几乎看不见）
警示 #F0542A  珊瑚红，只用于「错」的状态
```

规则：

- 一张卡只有**一个**强调色。要么薄荷，要么珊瑚，不能同时出现两种语义。
- 深色卡（`dark:true`）承担节奏，不是主题。12 张卡里固定 3 张（第 2/6/9/11 位）。
- 浅色卡上的辅助文字用 `rgba(18,20,18,.56)`，深色卡用 `rgba(237,233,225,.60)`。不要用灰色 solid，会脏。
- 允许的第四色只有一种：`#8E8A80` 之类的中性灰，用来画"群众/背景"。

## 2 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 中文大字 | `900 {n}px "Noto Sans SC"` | 这个字重的横竖比例最接近参考片 |
| 编号数字 | `900 {n}px "Arial Black"` | **必须用 fitText 横向压缩**，Arial Black 比原字体宽约 18% |
| 英文/代码/页脚 | `{w} {n}px Consolas` | 等宽，字距 3–7px 手动加 |
| 中文正文 | `600 {n}px "Noto Sans SC"` | 副标用 600，不要 700 |

硬规则：

1. 所有中文长句走 `fitText(str, x, baseline, targetW, font, color)`，按目标宽度反算缩放。**不要靠调字号凑宽度**——不同字的宽度不一样，调字号会让每张卡的标题大小不一致。
2. 英文小标必须大写 + 加字距（6–7px）。加了字距才有"仪表盘"的味道。
3. 一屏最多两种字重。

## 3 版式

左栏是**五层堆叠**，层与层的间距靠基线定，不靠 flex：

```
编号      基线 338     字面宽 326（含末尾小圆点）
中文标题  基线 540     2 字 196px / 3 字 158px / 长标题 fitText
英文小标  y 610        27px / 字距 6.8
短横      y 673        47×7 px，强调色
副标      y 695        37px，x=166（短横右侧）
代码标签  y 777        20px / 字距 3.4 / 强调色
代码正文  y 816        27px，末尾一个 11×23 的光标块
页脚      y 952        20px / 字距 4.2 / 透明度 .55
```

演示舞台：`883..1792 × 126..906`。四角画 44px 的直角括号（透明度 .26），右上角 `FIG.xx`，底部 24 格刻度条 + 当前进度实心格。

竖版 `LAY_V` 是另一套数值：编号基线 420 / 标题 630 / 英文 696 / 副标 774 / 舞台 64..1016 × 812..1588。**竖版不是横版等比缩小**，它是重新排的。

## 4 动效

缓动函数库（都在 `film.html` 顶部）：

| 函数 | 用途 |
|---|---|
| `outExpo` | 元素归位、卡片飞入。前 30% 走完 80% 距离 |
| `outBack(t, 1.25–2.2)` | 弹出式出现（数字、盖章、徽标） |
| `inOutCubic` | 位移类（拖拽、扫描、甩镜） |
| `springOut` | 弹性落点（球体、指示器） |
| `inv(a,b,t)` | 把绝对时间转成某段的 0–1 进度，**所有演示都用这个入口** |

节奏约定：

- 文字擦入 **0.16s**，从左往右 clip 揭开，同时透明度从 0 起。不是淡入。
- 切卡时不要用交叉溶解。用硬切 + 前 0.1s 的横向拖影（whip）。
- 演示动作在 `u = 0.5~0.65` 之间到高潮（撞击、盖章、进度满格），给后半段留 0.3s 的"结果停留"。**观众需要时间读结果**。
- 数字与读数用等宽字体 live 更新（24.0px → 0.0px），变化本身就是内容。

## 5 质感

- 颗粒：一张 512×512 的噪点图平铺全屏，浅色卡 `multiply` 透明度 .40，深色卡 `screen` .55。这一层是"印刷感"的来源，去掉就变塑料。
- 深色卡不要加暗角，会糊。
- 圆角只用 3–6px。大圆角是移动 App 的语言，不是这套。
- 阴影只用在球体下方，且是径向渐变 + 4px 模糊，不要用 `shadowBlur` 画卡片。
