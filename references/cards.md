# 十二卡文案写法

12 张卡的文字量非常小：2 + 1 行 + 1 个短句 + 1 行代码。**写得像说明书，不要写得像广告。**这套视觉的说服力来自"具体"，一旦换成形容词就废了。

## 字段规格

| 字段 | 长度 | 规则 |
|---|---|---|
| `cn` | 2 字（最多 3） | 动词或名词，动宾结构优先：「吸附」不行就「对齐」 |
| `en` | ≤ 14 字符，全大写 | 中文的直译，不要另起炉灶 |
| `sub` | ≤ 12 汉字 | **一句人话**，把这一页讲的是什么说清楚，可以有情绪 |
| `api` | ≤ 30 字符 | 一行像真的能跑的代码/命令，是这一页的"证据" |
| `dark` | 布尔 | 第 2/6/9/11 张为 true |
| `demo` | 函数名 | 这一页画什么，见 SKILL 的十二原语表 |

## 四个字段各写什么

### cn：一个动作

- ✅ 画布、时间轴、吸附、门控、渲染
- ❌ 强大的编辑能力、极致体验（四个字塞不进 196px 的格子里，也不具体）

### en：直译，不要诗意

- ✅ CANVAS、TIMELINE、SNAP、GATE
- ❌ POWERFUL、AMAZING、SMART WORKFLOW

### sub：说人话，允许带刺

这是全套文案里唯一有情绪的位置，用好它。判断标准：这句话能不能让目标用户心里"咯噔"一下。

| 平庸 | 好 |
|---|---|
| 高效完成剪辑工作 | 拖到哪，看到哪 |
| 智能字幕识别 | 逐条对时，不压人脸 |
| 云端同步 | 本地优先，素材不出本机 |
| 高质量渲染 | 排队导出，进度说话 |

句式模板：**「动词 + 到哪/怎么 + 结果」** 或 **「不 + 别人都在犯的错」**。

### api：一行假的但像真的命令

这一行是整套设计的锚点——它让"能力"变成"接口"，观众会觉得背后真有东西。规则：

- 必须包含符号：`(` `)` `.` `=` `→` `-`
- 用真实存在的命名习惯（snake_case 或 dot notation，别混）
- 数值要具体：`-12dB`、`8px`、`1080p·60`，不要 `'high'`

| 空泛 | 好 |
|---|---|
| `auto_edit()` | `caption.avoid(face, 40px)` |
| `render_video(quality)` | `render(1080p·60) → mp4` |
| `ai_assistant()` | `mcp.tool('caption.shift',-40)` |

## 十二张卡的结构

不要 12 条平铺的同级能力，按"三段"排，情绪才有起伏：

```
01–03  地基     观众最熟、最容易被说服的三个（把门槛降到最低）
04–08  流水线   中间五张，越往后越"高级"，是产品差异化的地方
09–11  门槛     审核 / 导出 / AI——讲"我替你把关"
12     信任     开源、本地、边界。收在信任上，不要收在功能上
```

深色卡落在 02 / 06 / 09 / 11，正好是每个段落的第二张和"门槛段"的第一张，明暗变化本身就是分段标记。

## 三种选题模板

### A 产品能力型（最常用）

12 个操作，从最基础到最自动。示例（剪辑工作台）：

> 画布 / 时间轴 / 字幕 / 关键帧 / 音频 / 转场 / 吸附 / 属性 / 门控 / 渲染 / 一句话 / 开源

### B 方法论型

12 个步骤，每步一个动作。适合课程、咨询、SOP。示例（选题→发布）：

> 选题 / 竞品 / 钩子 / 结构 / 拍摄 / 剪辑 / 包装 / 封面 / 审核 / 发布 / 复盘 / 复用

注意：方法论型的 `api` 行要换成"检查项"而不是代码，否则违和。例如 `hook.within(3s)`、`cover.face(60%)`。

### C 痛点对照型

前 6 张是"错的样子"，后 6 张是"对的样子"，同一组演示左右各一遍。这种结构冲击力最强，但要求 12 个演示能成对出现（模板里 d03 / d07 天生就是成对的）。

## 开场与落版

### 开场钩子（0.4–0.8s，两个短句）

公式：**「已完成的事实」+「但是」**

- 片已生成 / 然后呢？
- 素材有了 / 谁来剪？
- 战略定了 / 谁去干？

第一句必须是观众已经拿到的成果（现在 AI 都能给他），第二句是成果之后卡住的地方。**第二句要短，越短越狠。**

### 落版主张（总览之后，1.9s）

结构：`{一个字}，{一个判断}`，前半句品牌色。

- 剪，是最后一公里
- 内容，是重复劳动
- 分发，才是产品

写法：先想清楚这条片真正在主张什么（不是功能，是立场），再压成一个 6–9 字的判断句。**不要出现品牌名**，品牌名在下面一行小字里。

## 自检

念一遍 12 条 `sub`，如果出现重复句式三次以上，重写。12 条里至少有 3 条要让人想截图。
